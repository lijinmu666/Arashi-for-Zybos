# 强行停止作用域应用

入口位于“Hook 功能设置”右上角的“更多”菜单。选择“强行停止作用域应用”后，确认对话框会说明操作范围；点“取消”不会执行，点“确认”后会请求 root 权限。

执行时重新读取 LSPosed 当前勾选的应用包名，并逐个发送 Android `am force-stop` 命令。设置、SystemUI、桌面等应用只有在当前作用域中才会被处理。`system`、`system_server` 和 Android 框架包会被排除，因此不会停止系统框架，也不会重启设备。Arashi 若处于作用域内，会在其他应用处理完成后延迟停止。

未授权 root 时会提示“没有权限”；若设备拒绝停止某个应用，会显示停止失败提示。停止 SystemUI 或桌面后，它们可能由系统重新启动。
